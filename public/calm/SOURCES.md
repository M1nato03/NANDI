# Calm sounds

Recorded loops for Calm (spec 35, delta 35b). Every file is CC0 on Freesound; each licence was checked on the
sound's page by the idea engine (28 Oct 2026), and each was screened for voices. Files are 75-second seamless
loops, renamed to `<id>.ogg`.
