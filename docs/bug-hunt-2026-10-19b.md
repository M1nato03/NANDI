# Two-day bug hunt · 19 October 2026

The local audit in `scripts/bug-hunt.mjs` runs an isolated profile at each of 390×844 and 360×800 with the Playwright clock set to 19 October noon, 23:40, 20 October 01:45 and 08:30, then 2 November 09:00. A second profile at each width leaves a planned task unfinished and skips the lights-out check-in. The run uses the installed Edge channel when Chromium is unavailable and has a 900-second watchdog. Its JSON report and failure screenshots are written under ignored `test-results/bug-hunt-2026-10-19/`.

## Fixed
